# Quantum Casino
## Summary
- This project use quantum mechanics in hazard games.
- Idea: while absobing preliminary lessons before hackaton, we got an idea of implementing Grover's algorhitm in a fun way - that we can use its properties in first ever existing quantum casino - idea by us - which functionality is defined more detailed in following steps.
- Solution: we use Grover's algorhitm to bring the hazard into the enviroment. Firstly, user do not bet on exact number, he bets on number of iterations, in which he thinks algorhitm can get the correct number. That way he can be more and more sure in hitting correct number, but by buying more iterations, his prize will be lower so he will have to place bigger bet. And secondly, Grover's can be overcooked, so when he will hit that point, his chances of winning will instantly drop to zero without him noticing, which is second hazardeous thing in our casino. To understand it deeper, please, see the "Logic & quantum computing" part.
- Result: casino earns money from people, who can not tell stop to themselves, because by increasing iterations they can be more sure, but also lose everything.
